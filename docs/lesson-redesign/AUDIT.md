# Audit: lessons before and after (2026-11-27)

Played as a made-up TEST- boy with `node tools/lesson-redesign/audit.js` at Chromebook size (1366×768). Pictures of the old lessons: `audit-before/`; of the new ones: `../screens/new-lessons/`.
A "Next tap" only shows more; a "thinking tap" answers or builds something.
